# Алтын ғасыр 📜 — қазақ әдебиеті ойын түрінде

Қазақ әдебиетінің алтын ғасырындағы 13 тұлғамен (Дулат Бабатайұлынан Бейімбет Майлинге дейін) танысуға арналған веб-қосымша (PWA).
Android мен iPhone-да жұмыс істейді, телефонның басты экранына қосымша ретінде орнатылады.

## Режимдер (7)
| | Режим | Мазмұны |
|---|---|---|
| 🖼️ | Кім бұл? | Тұлғаның фотосы шығады, 4 нұсқадан есімін тап |
| 📜 | Өлеңдер | Әр тұлғаның 1–2 өлеңі (барлығы 25 өлең) |
| 🪶 | Кімнің өлеңі? | Өлең жолдарын оқып, авторын тап |
| 🧩 | Сөзді тап | Өлеңдегі жоғалған сөзді тап (тиынға көмек алуға болады) |
| 🔎 | Тұлғаны тап | Шығармасы мен дерегі бойынша тұлғаны анықта |
| ⏳ | Уақыт желісі | Тұлғаларды туған жылы бойынша ретімен орналастыр |
| 🃏 | Жұбын тап | Фото мен есімді жұптастыр (мемори ойыны) |

Қосымша бөлімдер: 🏛️ Тұлғалар (өмірбаян, шығармалар, өлеңдер), 🏆 Жетістіктер, ⚙️ Баптаулар.
Ойын элементтері: XP мен деңгейлер (Шәкірт → Хакім), тиын, комбо, жүрек, жұлдыздар, күн мақсаты, күндер сериясы, 12 жетістік, дыбыс, діріл, анимациялар.

## GitHub Pages-ке жариялау
1. GitHub-та жаңа репозиторий ашыңыз (мысалы, `altyn-gasyr`).
2. **Add file → Upload files** басып, осы қалтадағы **барлық файлды** бірден таңдап жүктеңіз (ішкі қалта жоқ — бәрі бір жерде).
3. **Commit changes** басыңыз.
4. **Settings → Pages** → *Deploy from a branch* → **main** және **/(root)** → **Save**.
5. 1–2 минуттан кейін қосымша `https://СІЗДІҢ-ЛОГИН.github.io/altyn-gasyr/` мекенжайында ашылады.

## Телефонға орнату
- **Android (Chrome):** сілтемені ашып, қосымшадағы «Орнату» батырмасын немесе мәзірдегі ⋮ → «Басты экранға қосу» таңдаңыз.
- **iPhone (Safari):** «Бөлісу» ⬆️ → «На экран „Домой“».

## Фотолар мен мәтіндер
- Фотолар Уикипедия және Wikimedia Commons-тан алынған, қосымша оларды тікелей сол жерден жүктейді. Бір рет ашылған соң интернетсіз де көрінеді.
- Дулат Бабатайұлының шынайы фотосы сақталмаған — суретшінің портреті қолданылды. Шортанбайдың суреті Commons-та «отбасымен» деп берілген көне фото.
- Өлең мәтіндері: Wikisource, bilim-all.kz.

## Өзгерту
Барлық дерек (тұлғалар, өмірбаян, өлеңдер, сұрақтар) `index.html` ішіндегі `const P = [...]` массивінде. Өзгерткен соң `sw.js` ішіндегі нұсқаны (`altyn-gasyr-v1` → `v2`) ауыстырыңыз — сонда пайдаланушыларға жаңа нұсқа келеді.
